# Implementation Plan: Physical Play Dice (`pp-dice`) Module & Dev Setup

**Spec:** [`docs/superpowers/specs/2026-09-23-pp-dice-design.md`](../specs/2026-09-23-pp-dice-design.md)

## Task Breakdown

### Task 1: Toolchain Setup

- Initialize `package.json` with TypeScript, Vite, Vitest, ESLint, Prettier.
- Configure `tsconfig.json` for ES2022 / strict.
- Configure `vite.config.ts` to output ESM to `dist/` and handle Foundry sync.
- Create `.gitignore`, `foundryconfig.json.example`.
- Install dependencies via `npm install`.

### Task 2: Tier B & Tier C Documentation Architecture

- Generate `AGENTS.md` with:
  - Required sections (Language, Workflow Skills, Confidence Gate, Untrusted Input, Branch Workflow, Subagent Delegation).
  - Documentation Map table per Tier C recommendations.
- Create symlink `CLAUDE.md -> AGENTS.md`.
- Generate `CHANGELOG.md` (Keep a Changelog format).
- Generate `docs/DEVELOPMENT.md`.
- Establish documentation tree with `00-index.md` files:
  - `docs/spec/00-index.md` and `docs/spec/physical-dice-interception.md`.
  - `docs/design/00-index.md` and `docs/design/architecture.md`.
  - `docs/adr/00-index.md` and `docs/adr/0001-hybrid-roll-interception.md`.
  - `docs/dev/00-index.md` and `docs/dev/wsl-windows-workflow.md`.

### Task 3: Foundry VTT Module Manifest & Internationalization

- Create `src/module.json` compliant with Foundry v14.
- Create `lang/en.json` and `lang/fr.json`.
- Create `src/constants.ts`.

### Task 4: Context Manager & System Providers

- Create `src/providers/base.ts`: Abstract `RollContextProvider`.
- Create `src/providers/pf2e.ts`: PF2e provider (party check, alliance, secret check).
- Create `src/providers/generic.ts`: Fallback provider (`hasPlayerOwner`, `actor.type === "character"`).
- Create `src/core/context-manager.ts`: Composite context manager.
- Create unit tests in `tests/context-manager.test.ts` and run with `npm run test`.

### Task 5: Dice Interception Engine

- Create `src/core/interceptor.ts`:
  - Hook into `Roll.prototype._evaluate` or `Roll.identifyFulfillableTerms` using `libWrapper` with shim.
  - Determine when to bypass vs trigger manual fulfillment.
- Create unit tests in `tests/interceptor.test.ts`.

### Task 6: UI Resolver & Session Controls

- Create `src/ui/pp-dice-resolver.ts` extending `foundry.applications.api.ApplicationV2` (or `HandlebarsApplicationMixin(ApplicationV2)`).
- Create Handlebars template `templates/dice-resolver.hbs`.
- Create `src/ui/controls.ts` for quick toggle (scene controls & `Alt+P` hotkey).
- Create `src/styles/pp-dice.css` for compact dark-mode styling.
- Create `src/main.ts` as the module entry point hooking `init` and `ready`.

### Task 7: Build, Verification & Sync

- Verify all unit tests pass (`npm run test`).
- Verify strict lint passes (`npm run lint`).
- Verify typecheck passes (`npm run typecheck`).
- Verify build generates `dist/` and syncs to `/mnt/c/Users/stany/AppData/Local/FoundryVTT/Data/modules/pp-dice`.
